I build web scrapers, publish them on Apify, and keep them running when the sites
change underneath them. Each one reads a site the way the site serves itself to a
logged-out visitor, returns one clean row per thing you asked for, and tells you in
that row when it could not read something, rather than handing you an empty file.

The repos here are working examples: the problem, a Node and a Python script, and
real output from a real run. The write-ups live at
[simple-actor.github.io](https://simple-actor.github.io).

### Leads and local businesses

- [Google Maps Leads](https://apify.com/simple.actor/google-maps-leads): every business Maps lists for a search, plus the emails, phones and socials on its own website
- [Google Maps](https://apify.com/simple.actor/google-maps): places with rating, reviews, address, phone, website, hours and Place ID
- [Website Contacts](https://apify.com/simple.actor/website-contacts): emails, phones, socials, address and contact form from a list of domains
- [Business Profile](https://apify.com/simple.actor/business-profile): one business from a name and a town: its Google record, website contacts and social accounts

### Search and ads

- [Google Search](https://apify.com/simple.actor/google-search): web results, or Google News stories with links to the publisher
- [Google Images](https://apify.com/simple.actor/google-images): full-size image URLs, sizes and source pages
- [Google Short Videos](https://apify.com/simple.actor/google-short-videos): the Short videos tab across YouTube, TikTok, Instagram and more
- [Google Ads Transparency](https://apify.com/simple.actor/google-ads-transparency): every ad an advertiser runs, by name or website
